# Veröffentlichung

1. Führe `make test check-plugin check-docs-export` aus und prüfe den Diff.
2. Veröffentliche die Änderungen in `draftm0de/ai.plugin.interview-coach`.
3. Veröffentliche anschließend den Katalogeintrag in `draftm0de/ai.plugins`.
4. Synchronisiere **Draftmode AI Plugins** und prüfe beide Plugin-Einträge sowie die Installation von **Interview Coach**.

Keine Plugin-ZIPs, Versionsnummern, Tags oder GitHub Releases erforderlich. Commit und Push bleiben ausdrücklich freizugebende Schritte. Die grafische Host-Abnahme steht aus; lokale Strukturprüfungen ersetzen sie nicht. [Installation](installation.md).
