# Publication

1. Run `make test check-plugin check-docs-export` and review the diff.
2. Publish changes in `draftm0de/ai.plugin.interview-coach`.
3. Then publish the catalog entry in `draftm0de/ai.plugins`.
4. Sync **Draftmode AI Plugins**, check both plugin entries and install **Interview Coach**.

No plugin ZIPs, versions, tags or GitHub Releases are required. Commit and push require explicit authorization. Graphical host acceptance is pending; local structural checks do not replace it. [Installation](installation.md).
